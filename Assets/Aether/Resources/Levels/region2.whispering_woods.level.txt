# Project Aether - M4 Whispering Woods level.
#
# Source of truth for the second region. Runtime and editor consumers must derive their
# representations from this file; it is never hand-edited through a baked scene.
#
# Design goals:
# - the player leaves the open Greenway and enters a narrower, denser route;
# - encounters alternate with breathing spaces rather than becoming a combat corridor;
# - the silent zone is represented as a semantic story space, ready for a future audio backend;
# - the shortcut returns the player to the first checkpoint without creating a progression lock.
